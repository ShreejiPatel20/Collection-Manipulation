# Student Data Organizer

## Project Description

Student Data Organizer is a simple Python console application that helps manage student records. It allows users to add, display, update, and delete student information through a menu-driven interface. The program also displays all unique subjects offered by the students.

## Features

- Add new student records
- Display all student details
- Update existing student information
- Delete student records
- Display all unique subjects
- Menu-driven interface
- Simple and easy to use

## Technologies Used

- Python 3

## How to Run

1. Make sure Python 3 is installed on your computer.
2. Download or clone the project.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python Submition-03.py
```

## Menu Options

1. Add Student
2. Display All Students
3. Update Student Information
4. Delete Student
5. Display Subjects Offered
6. Exit

## Student Information Stored

Each student record contains:

- Student ID
- Name
- Age
- Grade
- Date of Birth
- Subjects
